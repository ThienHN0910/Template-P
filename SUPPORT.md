# Support

- **How-to questions and ideas:** start a [GitHub Discussion](https://github.com/ThienHN0910/Template-P/discussions).
- **Reproducible defects:** use the bug-report issue form and include the complete command, operating system, runtime versions, and a sanitized log.
- **Security concerns:** follow [SECURITY.md](SECURITY.md); do not report them publicly.

The maintained compatibility contract is the [current v2 compatibility contract](docs/reference/compatibility.md). New frameworks and blueprint requests are welcome, but require an owner and an automated verification path before they are described as supported.
